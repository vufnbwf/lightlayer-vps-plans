## FAQ

**香港服务器要不要备案？**
不需要 ICP 备案。香港机房不受大陆工信部管辖，域名解析就能访问。免备案不等于免监管，内容违规仍可能被处理；主要面向国内用户时，未备案域名在某些网络环境下访问体验会受影响。

**独服和 VPS 差在哪？**
VPS 是把一台物理机切成多份，高峰时 CPU、内存、磁盘 I/O 可能互相影响。独服的 CPU、内存、磁盘和 IP 独占，适合高并发、多站点、游戏服务、接口回源。轻量业务用 VPS 更省钱。

**10Mbps 够不够用？**
看业务。文字站、企业站、轻量 API、后台管理够用。视频、下载、大文件分发、图片站不够。10Mbps 峰值约 1.25MB/s，按这个估算日常流量。

**延迟多少算正常？**
同类 CN2 优化线路的公开测评三网平均 40–45ms，普通 BGP 48–55ms。LightLayer 没有公开实测，下单前要测试 IP 自己 ping。

**$56 和 $84 差在哪？**
$56 是 E3-1230、8G、240G SSD 加 1T HDD；$84 是 Gold 6138、32G、1T SSD，CPU 核心数和内存大很多，适合建站、外贸、轻量高并发。两者基础带宽都是 10Mbps 起，$84 促销款可选 15Mbps 全向或 20Mbps 国际。$84 原价 $120，用码后便宜 36 美元，但限量 20 台。

**续费会不会涨？**
